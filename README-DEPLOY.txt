- shraddha-portrait-transparent.png (portrait cut-out)

Deploy:
1. Extract this ZIP.
2. Upload all extracted files to the root of your GitHub Pages repository.
3. Replace files with the same names.
4. Keep the HTML files, stylesheet and portrait together in the root folder.
5. In GitHub Settings → Pages, confirm the publishing source is the main branch and / (root), if using branch-based Pages.
6. Wait a few minutes for publishing, then open the site URL.

Readability:
Light panels use dark text. Dark burgundy panels use light text. Project 1 company cards have dark body text for readability against the beige background.

This ZIP includes concise portfolio summaries and selected figures, not the original research papers or calculation workbooks.
